# BOM 提示词（图片输入 → 一个 Excel 表格 · 三个修改方案共用）

## 使用方法
将本提示词分别与 `修改方案/修改方案1.png`、`修改方案2.png`、`修改方案3.png` 一起输入，同一段提示词输入三次，分别产出 `BOM-方案1.xlsx`、`BOM-方案2.xlsx`、`BOM-方案3.xlsx`。

## 提示词正文

```text
请读取我提供的户型图图片，根据图中标注的房间名称、面积和尺寸线，估算该户型建造时各构件的数量，最终输出为一个 Excel 文件（.xlsx），整个文件只包含一张 BOM 表格。

【输入】
- 一张2D户型图（含每个房间的名称和面积标注、外圈尺寸线）。

【估算规则】
1. 按户型图标注的面积和尺寸线推算各构件数量；层高按2.8m计；
2. 墙体：区分外墙与新增内隔墙，按面积（长度×层高）估算；
3. 地面：按各房间标注面积计算，加5%损耗；
4. 墙面：按房间周长×层高扣除门窗洞口估算，加10%损耗；
5. 门、窗、卫生洁具、橱柜等按户型图中的数量/位置逐个统计；
6. 数量保留两位小数，并在"计算依据"列写明推算过程。

【输出要求】
- 输出一个 .xlsx 文件，只含一张工作表，表名为"BOM"；
- 表格为规范工程表格：有标题行、连续序号、统一单位（㎡/m/樘/套/个/延米），禁止散文描述；

表头固定为以下8列：
| 序号 | 构件名称 | 所属房间/部位 | 规格/说明 | 单位 | 数量 | 计算依据 | 备注 |

- 构件按类别分组排列：墙体工程 → 地面工程 → 墙面工程 → 门窗工程 → 卫浴 → 厨房 → 其他；
- 表格最后一行为"合计"行（仅对可合计的列说明，不可合计的注明"—"）；
- 所有数量必须可复算：数量 与 "计算依据" 中的算式结果一致。
```
