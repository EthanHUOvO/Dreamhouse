# 效果图提示词（45° 斜视渲染 · 三个修改方案共用）

## 使用方法
将本提示词分别与 `修改方案/修改方案1.png`、`修改方案2.png`、`修改方案3.png` 一起输入 AI 绘图模型（图生图），同一段提示词输入三次，产出三张 45° 斜视效果图，编号为 `效果图1.png`、`效果图2.png`、`效果图3.png`，编号与修改方案一一对应。

## 提示词正文

```text
请基于我提供的这张2D户型图，生成一张45度斜视轴测（3D鸟瞰）效果图。

【视角与构图】
- 45度俯视斜视角度（轴测视角），从户型图的东南方向看过去，可以清晰看到每个房间的内部布局；
- 所有墙体拉起为约2.8米高的立体墙体，靠近观察者一侧的墙体可以做剖切降低处理，确保内部可见；
- 不要改变户型图中的房间布局、隔墙位置和房间数量，严格按平面图还原。

【材质与风格】
- 现代简约装修风格：卧室铺浅木色地板，客餐厅铺浅灰色地砖，卫生间/厨房铺防滑瓷砖并配白色洁具和浅色橱柜；
- 墙面为白色/浅灰色乳胶漆；
- 适当摆放与房间功能匹配的简约家具（床、衣柜、沙发、餐桌、马桶、洗手台、灶台等），比例协调；
- 柔和的自然光照明，整体明亮干净。

【输出要求】
- 高质量3D渲染效果图，分辨率尽可能高；
- 不要添加文字标注、水印或人物；
- 背景为纯白色或浅灰色。
```
