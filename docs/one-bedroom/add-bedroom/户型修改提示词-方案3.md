# 户型修改提示词 · 方案3（压缩厨房隔出客卫，卧室竖向分隔）

## 使用方法
将本提示词与 `原始图片-1室1厅1卫1厨` 中的原始户型图一起输入 AI 绘图模型（图生图），生成改造后的 2D 户型图。

## 提示词正文

```text
请基于我提供的原始户型图（1室1厅1卫1厨，含卧室19.1㎡、客餐厅27.1㎡、厨房14.8㎡、卫生间6.9㎡、阳台5.6㎡、储物间3.2㎡）进行户型改造，输出一张新的2D户型图。

【硬性约束】
1. 最外侧墙壁、外窗、入户门的位置和尺寸绝对不能改动；
2. 只允许在房屋内部增加或删除隔墙；
3. 改造后房间数量必须严格为：2个卧室、1个客餐厅、2个卫生间、1个厨房。

【本方案的改造细节】
1. 右上"厨房"（14.8㎡，约2586mm宽×5708mm高）面积过大，沿水平方向在距其底部约2200mm处加一道隔墙，隔出的下部区域（约2586mm×2200mm）改造为第二个卫生间，标注为"卫生间"，开门朝向客餐厅；厨房保留上部约3508mm高的区域；
2. 将左上角的"卧室"（19.1㎡，约4475mm宽）沿竖直方向加一道隔墙一分为二：靠左约2600mm宽作为"主卧"，靠右约1875mm宽作为"次卧"，两间卧室的门均开向南侧；
3. 原卫生间（6.9㎡）、客餐厅、阳台、储物间的位置和范围保持不变；
4. 新增隔墙上合理布置门洞，保证每个房间都可以进入。

【输出要求】
- 保持与原图一致的绘图风格：黑色粗墙体、木地板色卧室、灰色卫生间/厨房、米色客餐厅；
- 每个房间标注房间名称和面积；
- 保留四周尺寸标注线；2D平面图视角，不要透视。
```
