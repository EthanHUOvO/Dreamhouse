# 户型修改提示词 · 方案1（储物间改第二卫生间，其余不动）

## 使用方法
将本提示词与 `原始图片-1室1厅1卫1厨` 中的原始户型图一起输入 AI 绘图模型（图生图），生成改造后的 2D 户型图。

## 提示词正文

```text
请基于我提供的原始户型图（1室1厅1卫1厨，含卧室19.1㎡、客餐厅27.1㎡、厨房14.8㎡、卫生间6.9㎡、阳台5.6㎡、储物间3.2㎡）进行户型改造，输出一张新的2D户型图。

【硬性约束】
1. 最外侧墙壁、外窗、入户门的位置和尺寸绝对不能改动；
2. 只允许在房屋内部增加或删除隔墙；
3. 改造后房间数量必须严格为：1个卧室、1个客餐厅、2个卫生间、1个厨房。

【本方案的改造细节】
1. 将右上角的"储物间"（3.2㎡）改造为第二个卫生间，标注为"卫生间"，其与厨房之间的隔墙保持不变，开门朝向厨房或客餐厅方向；
2. 卧室（19.1㎡）、客餐厅、厨房、原卫生间（6.9㎡）、阳台的位置和范围保持不变；
3. 如新增卫生间需要开门，在内部隔墙上布置门洞，保证其可以进入。

【输出要求】
- 保持与原图一致的绘图风格：黑色粗墙体、木地板色卧室、灰色卫生间/厨房、米色客餐厅；
- 每个房间标注房间名称和面积；
- 保留四周尺寸标注线；2D平面图视角，不要透视。
```
